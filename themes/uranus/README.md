# Uranus — 实验性主题

非对称布局 · 大胆留白 · 先锋字体排印

## 设计理念

Uranus 打破常规布局，采用非对称交错卡片排列、超大文字层级、大胆的装饰色块和粗犷的排版对比。适合寻求个性、不拘一格的内容创作者。灵感源自天王星的侧卧自转轴。

## 配色

| 模式 | 背景 | 强调色 | 文字 |
|------|------|--------|------|
| 亮色 | #f0fdfa（青绿） | #00d2ff（氰蓝） | #0f172a |
| 暗色 | #0f172a（深蓝） | #22d3ee（青蓝） | #f1f5f9 |

## 自定义配置

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `accentColor` | input | 强调色 | `#00d2ff` |
| `layoutStyle` | select | 布局风格 (asymmetric/split/single-column) | `asymmetric` |
| `animationLevel` | select | 动效强度 (none/subtle/full) | `subtle` |
| `showDecorativeElements` | toggle | 显示装饰元素 | `true` |
| `showDarkModeToggle` | toggle | 显示暗色模式切换 | `true` |
| `showSidebar` | toggle | 显示侧边栏 | `true` |
| `postsPerPage` | input | 每页文章数 | `10` |
| `showTagsInPost` | toggle | 文章底部显示标签 | `true` |
| `socialGithub` | input | GitHub 用户名 | `""` |
| `socialTwitter` | input | Twitter 用户名 | `""` |
| `footerText` | input | 页脚自定义文字 | `""` |
| `customCSS` | textarea | 自定义 CSS | `""` |

## 安装

1. 将 `uranus` 文件夹复制到 Gridea Pro 的 `themes/` 目录
2. 在管理后台的「主题」中选择 Uranus
3. 按需设置外观选项
