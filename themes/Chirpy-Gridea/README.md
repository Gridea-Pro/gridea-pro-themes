# Chirpy For Gridea Pro

![效果图](screenshot.png)

这是一个把[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)移植到 **Gridea Pro** 的主题。

## 目录说明

```text
Chirpy-Gridea/
├── config.json
├── screenshot.png
├── assets/
│   ├── media/
│   ├── scripts/
│   └── styles/
└── templates/
    ├── base.html
    ├── index.html
    ├── blog.html
    ├── memos.html
    ├── notes.html
    ├── friends.html
    ├── post.html
    ├── archives.html
    ├── tags.html
    ├── tag.html
    ├── 404.html
    └── partials/
```


## 使用方式

1. 把整个 `Chirpy-Gridea` 文件夹复制到 Gridea 主题目录
2. 在 Gridea 中选择这个主题


## Twikoo 评论

- 在主题设置的 `文章` 分组里打开 `启用 Twikoo 评论`
- 在 `Twikoo 服务地址 / envId` 中填写你的 Twikoo 服务地址
- 例如：`https://twikoo.example.com/`
- 如果你使用云开发版本，也可以直接填写云环境 `envId`
- 保存后，文章页底部会自动加载评论区

## Markdown 扩展写法

- 在文章正文里单独写一行 `@[bilibili](BV1vDugzhEu6)`，会自动渲染成 B 站内嵌视频
- 也支持完整链接写法，例如 `@[bilibili](https://www.bilibili.com/video/BV1vDugzhEu6)`
