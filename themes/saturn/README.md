# Saturn — 卡片模块化主题

环状装饰 · 卡片模块化 · 灵动布局

## 设计理念

Saturn 以「环」（Ring）为核心视觉语言，用大圆角卡片、彩色左侧边环、渐变环装饰线来塑造温暖、模块化、富有节奏感的博客体验。灵感源自土星的光环。

## 配色

| 模式 | 背景 | 强调色 | 文字 |
|------|------|--------|------|
| 亮色 | #fffbeb（暖琥珀） | #ff6b6b（珊瑚） | #1a1a2e |
| 暗色 | #1a1a2e（深紫） | #ff6b6b（珊瑚） | #f1f5f9 |

## 自定义配置

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| `accentColor` | input | 强调色 | `#ff6b6b` |
| `cardBorderRadius` | select | 卡片圆角大小 (small/medium/large) | `medium` |
| `cardShadow` | select | 卡片阴影强度 (light/medium/strong) | `medium` |
| `showGradientAccent` | toggle | 显示渐变装饰 | `true` |
| `showDarkModeToggle` | toggle | 显示暗色模式切换 | `true` |
| `layout` | select | 页面布局 (right-sidebar/full-width) | `right-sidebar` |
| `showSidebar` | toggle | 显示侧边栏 | `true` |
| `postsPerPage` | input | 每页文章数 | `10` |
| `showTagsInPost` | toggle | 文章底部显示标签 | `true` |
| `socialGithub` | input | GitHub 用户名 | `""` |
| `socialTwitter` | input | Twitter 用户名 | `""` |
| `footerText` | input | 页脚自定义文字 | `""` |
| `customCSS` | textarea | 自定义 CSS | `""` |

## 安装

1. 将 `saturn` 文件夹复制到 Gridea Pro 的 `themes/` 目录
2. 在管理后台的「主题」中选择 Saturn
3. 按需设置外观选项
